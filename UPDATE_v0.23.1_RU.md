# D&D Card Table v0.23.1 — урон и концентрация

Это накопительное обновление существующего проекта. Готовый русский перевод включён в архив. Пользователь подтвердил успешный запуск предыдущей v0.23.0 с переводом.

## Что исправлено

- Урон из листа персонажа и из сражения проходит через одну обработку. Временные хиты поглощают урон первыми; остаток уменьшает обычные хиты.
- Сражение читает актуальные хиты персонажа. Старое значение в сражении больше не отменяет лечение или отдых, выполненные в листе персонажа.
- Каждый отдельный ввод урона создаёт свою проверку концентрации, даже если урон полностью поглощён временными хитами. Несколько ударов образуют очередь.
- Сложность по правилам 2024: `min(30, max(10, floor(урон / 2)))`. Например, 23 урона дают Сл 11. Ранее округление было вверх и отсутствовал предел 30.
- При снижении обычных хитов до 0 концентрация заканчивается. Успешный спасбросок закрывает одну проверку; провал прекращает концентрацию и очищает очередь.
- Панель концентрации и кнопка спасброска доступны у каждого соответствующего персонажа в сражении. Результат обновляет только панель этого персонажа. Преимущество от Eldritch Mind сохранено.
- Повторная отправка уже выполненной проверки не тратит следующую. Состояние и журнал броска записываются в одной транзакции.
- В листе персонажа и сражении можно раскрыть «Временные хиты» и установить число. Оно заменяет прежнее значение, а не прибавляется. Ноль очищает запас.
- Настройки `.env` загружаются до модулей локализации, чтобы заданный `LOCALIZATION_PACK` учитывался при запуске сервера.

## Установка поверх работающей v0.23.0

1. Остановите сервер через `Ctrl+C`.
2. Сохраните копию рабочей папки. Резервная копия PostgreSQL создаётся отдельно: копирование файлов приложения не копирует базу.
3. Распакуйте `dnd-card-table-v0.23.1-combat-fixes-ru.zip`. Скопируйте его содержимое в рабочую папку проекта с объединением папок и заменой совпадающих файлов. Сохраните прежний `.env` и остальные файлы базового проекта.
4. Из папки с `package.json` запустите:

```powershell
npm.cmd run web
```

5. В браузере нажмите `Ctrl+F5`. Внизу страницы должна отображаться v0.23.1.

Для перехода с уже работающей v0.23.0 новые зависимости, миграции и повторный импорт каталога не требуются. Порядок полной подготовки рабочей копии описан в `INSTALL_RU.md`. Архив не предназначен для установки в пустую папку.

Если есть собственные изменения переводов, перед заменой сохраните свой `data/translations/ru.json`. Поставляемый пакет идентичен версии, выданной вместе с v0.23.0; для этого обновления заменять собственный перевод не требуется.

## Как проверить на тестовом персонаже

1. Возьмите персонажа с 40 обычными хитами и активным заклинанием концентрации.
2. Раскройте «Временные хиты», установите 10.
3. Добавьте персонажа в сражение. В поле изменения хитов введите `-23` и примените: ожидаются 27 обычных хитов, 0 временных, проверка концентрации Сл 11.
4. До спасброска примените ещё `-6`: ожидаются 21 хит и две ожидающие проверки. Первый успешный спасбросок оставляет вторую; любой провал прекращает концентрацию.
5. Проверьте лечение положительным числом: оно ограничено максимумом хитов и не восстанавливает временные хиты.
6. Если есть второй концентрирующийся персонаж, выполните проверку первого: панель второго должна остаться прежней.

Вводимый урон должен уже учитывать сопротивления, иммунитеты и уязвимости. Каждое применение отрицательного числа считается отдельным источником урона. Особые исключения способностей и все условия потери концентрации ещё не автоматизированы.

## Проверки разработчика

- 119 тестов: все прошли, пропусков нет.
- Среди них — проверки SQL на PostgreSQL-движке PGlite: хиты в нескольких сражениях, временные хиты, очередь, защита от повторного запроса, откат при ошибке записи журнала.
- Проверены локализованные формы, сохранность идентификаторов и обновление только нужной панели.
- Аудит интерфейса: 1183 из 1183 строк покрыты.
- Пакет каталога: 7276 машинных переводов, 849 терминов, `pending: 0`, `complete: true` по приложенному снимку.
- `ru.json` и английский `manifest.json` побайтно совпадают с поставкой v0.23.0.

Браузерная визуальная проверка нового экрана не завершилась: локальный тестовый стенд не открылся в доступном браузере. Пользовательская база не подключалась; проверки SQL выполнялись на изолированных тестовых данных.

Правила сверены с первоисточником: [Concentration — D&D Beyond Basic Rules 2024](https://www.dndbeyond.com/sources/dnd/br-2024/rules-glossary#Concentration), [Damage and Healing](https://www.dndbeyond.com/sources/dnd/br-2024/playing-the-game#DamageandHealing).
