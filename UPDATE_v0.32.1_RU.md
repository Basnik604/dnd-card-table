# D&D Card Table v0.32.1 — доки Workspace

Локации, инспектор и подсказки перемещаются в левую, правую и нижнюю зоны. Перетаскивайте заголовок панели или используйте список расположения. Несколько панелей в одной зоне становятся вкладками. Скрытые и неактивные формы остаются на странице и сохраняют черновики.

Боковые зоны меняют ширину, нижняя — высоту. Перетаскивайте разделитель или выберите его клавишей Tab: стрелки изменяют размер, Home/End задают границы. Вкладки поддерживают стрелки и Home/End. На экране до 900 px зоны располагаются вертикально; сохранённые размеры для большого экрана остаются прежними.

Личная раскладка v2 сохраняет расположение, активные вкладки, размеры, видимость, режим карты и вкладку инспектора. Настройки v1 преобразуются автоматически; старая запись остаётся. Сброс возвращает исходную раскладку. Изменение Workspace не меняет игровые данные.

## Установка для Windows

1. Остановите старый Node-сервер через Ctrl+C.
2. Выберите ветку `feature/v0.32.1-workspace-docks` в GitHub Desktop или скачайте её через Code → Download ZIP.
3. Используйте прежнюю рабочую `.env` и PostgreSQL-базу. Новых миграций нет.
4. В папке проекта: `npm.cmd ci`, затем `npm.cmd run web`.
5. Откройте http://localhost:3000/tabletop и нажмите Ctrl+F5. Внизу должна быть версия 0.32.1.

## Ручная проверка

- Перенесите инспектор во все три зоны. Перенесите подсказки в ту же зону и переключите вкладки.
- Введите название карты/токена без сохранения. Перенесите панель, измените размер, закройте и верните, сбросьте раскладку: черновики остаются.
- Измените размер каждой зоны мышью и клавиатурой. Карта остаётся доступной; размер клетки и положение токенов прежние.
- Закройте активную вкладку: откроется следующая. Обновите страницу и смените этаж: сохранённая раскладка остаётся.
- Включите «Только карта», выберите токен: откроется его инспектор.
- Проверьте узкое окно, русский и английский интерфейс.

Проверки: `npm test`, `npm run i18n:audit:ui`, `npm run test:tabletop:browser`. Точные результаты текущего коммита указаны в PR.

Плавающие окна и отдельные панели персонажа — последующие этапы. PR 0.32.1 строится поверх открытого PR #1 с 0.32.0.
