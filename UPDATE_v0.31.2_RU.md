# v0.31.2 — коллекция токенов

Накопительное обновление существующего рабочего проекта. Включает объединение значков v0.31.1 и этажи v0.31.0. Изображения поставляются отдельным пакетом, который устанавливается один раз.

## Что добавлено

- Из присланного архива подключены все **1924 исходных файла**: **1860 уникальных изображений**, 64 точных повтора объединены. Исходные PNG 256×256 сохранены без переработки.
- Коллекция стала основным источником изображений в автоматическом режиме. Монстр получает подходящий вариант по исходному названию из бестиария; переименование токена не меняет это сопоставление. Для одинаковых монстров варианты чередуются, когда они есть.
- Вариант автоматического изображения сохраняется при переносе между этажами, даже если меняется номер монстра. Выбранное вручную изображение также сохраняется.
- Каталог с поиском, 103 разделами и подразделами, русскими названиями разделов и страницами по 48 картинок. Варианты ищутся по английским именам файлов и распространённым русским названиям: «зомби», «волк», «красный дракон», «торговец» и другим. Точные совпадения находятся выше похожих названий.
- Разделы повторяют организацию исходного набора. Тип существа, характеристики и правила D&D в бестиарии не меняются из-за расположения картинки в папке.
- Собственный портрет персонажа имеет приоритет в автоматическом режиме. Для персонажа без портрета учитываются имя и класс. Если подходящей картинки нет, остаётся типовой значок; мастер может выбрать изображение вручную.
- Цветные изображения сохраняют оригинальные цвета. Можно менять внешнюю рамку и отношение «союзник / нейтральный / враг». Цвет типового значка по-прежнему настраивается отдельно.
- Старый каталог из 61 значка доступен через режим «Только значок». Явно выбранный значок и загруженный портрет сохраняются.

Названия самих картинок остаются исходными английскими. Подбор не гарантирует отдельный арт для каждого существа бестиария: набор содержит и общие образы, и авторские варианты. При отсутствии возрастного или размерного варианта допускается изображение базового существа.

## Установка в Windows

Нужны **оба архива**:

1. `dnd-card-table-v0.31.2-token-collection-ru.zip` — код обновления.
2. `dnd-token-pack-first-collection-v1.zip` — изображения и их каталог.

Остановите сервер через **Ctrl+C**. Распакуйте содержимое обоих архивов **поверх одной и той же прежней рабочей папки**, объединяя папки и заменяя совпадающие файлы. Папка с `package.json` должна содержать:

- `src/web/tabletop-art.mjs`;
- `db/migrations/023_tabletop_token_art.sql`;
- `data/token-packs/first-dnd/manifest.json`;
- `data/token-packs/first-dnd/images/` с 1860 PNG.

Сохраните прежний `.env` и базовые файлы установки. Архив кода является обновлением, а не отдельной установкой с новой базой. Затем запустите из рабочей папки:

```powershell
npm.cmd run web
```

Откройте игровой стол и нажмите **Ctrl+F5**. Внизу страницы должна отображаться версия **0.31.2**.

Новых зависимостей нет. Дополнение схемы 023 применяется автоматически при открытии стола; повторный импорт существ и пересоздание токенов не требуются.

Пакет изображений находится отдельно от обновлений кода. Сохраняйте папку `data/token-packs` при следующих обновлениях. Не накладывайте старый ZIP кода поверх нового: он заменит программу старой версией.

## Как проверить за несколько минут

1. Откройте существующий стол и добавьте из бестиария двух зомби. В автоматическом режиме появятся картинки коллекции с номерами; при наличии нескольких вариантов их изображения будут различаться.
2. Выберите токен → **«Выбрать изображение из набора»**. Найдите «красный дракон», затем очистите поиск через «Показать весь набор». Должно быть найдено **1860 изображений**, всего **39 страниц**.
3. Выберите раздел **«Звери / Медведи»**, нажмите на картинку, измените цвет рамки и нажмите **«Сохранить токен»**. Выбор в каталоге сам по себе ещё не сохраняет изменения.
4. Обновите страницу, перенесите токен на другой этаж и верните обратно. Изображение и цвет рамки должны сохраниться; положение восстанавливается, если место свободно.
5. Проверьте персонажа со своим портретом и переключение «Изображение из набора» / «Только значок» / «Автоматически». Старые значки и портреты остаются доступны.

## Если коллекция не появилась

- Сообщение об установке пакета обычно означает, что `data/token-packs/first-dnd` попала во вложенную папку архива, а не рядом с рабочей папкой `src`. Исправьте путь и перезапустите сервер.
- Если пакет установлен при работающем сервере, требуется перезапуск: каталог считывается и сохраняется в памяти процесса.
- При отсутствии пакета стол продолжает работать с типовыми значками. Ручной выбор изображения остаётся записанным и восстановится после возвращения пакета и перезапуска.
- Если токен показывает старый значок, проверьте поле «Вид токена»: режим «Только значок» намеренно сохраняет этот выбор.

## Проверки выпуска

Пройдены 239 автоматических тестов; все 1737 строк интерфейса имеют перевод. Проверки охватывают миграцию старой схемы, сохранение выбранного изображения, переносы, стабильность автоматического варианта, приоритет портретов, отсутствие пакета, права доступа к картинкам и корректность поиска. В Chromium пройдены 45 сценариев; проверены каталог, поиск, страницы, сохранение, ошибки сети, перенос и мобильная ширина. Все PNG сверены с исходными байтами; архивы проверяются после повторного скачивания.

Проверки используют изолированную PostgreSQL-совместимую PGlite и Chromium. Пользовательская установленная база в них не участвует.
