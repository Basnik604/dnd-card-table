# v0.36 — единая версия и сохранность данных

Релизная основа: Подтверждено: итоговая ветка v0.35.5 содержит все головы PR #1–10; объединение не требует потери промежуточных изменений.

Проверки выпуска: миграции чистой и существующей БД; повторный запуск без изменения данных; резервная копия PostgreSQL с изображениями и каталога data; проверка целостности; восстановление только в новую пустую БД; полный CI игрового стола.
