# D&D Card Table v0.36.0

Локальный игровой стол мастера: карты, сцены и токены, свободные окна, связанные панели персонажей и бой с подтверждением результата. v0.36 объединяет этапы 0.32–0.35 и добавляет проверяемую сохранность данных. Подключение игроков и серверные права — следующий этап 0.37.

## Новое в 0.36

- Единая релизная версия с сохранённой историей всех этапов.
- Журнал миграций, контрольные суммы и защита от повторного выполнения старых исправлений.
- Полная копия PostgreSQL (включая карты/портреты) и каталога data.
- Проверка целостности и восстановление только в отдельную пустую БД и новую файловую папку.
- Автоматическая проверка свежей установки, обновления 0.31.2/0.35.5 и восстановления на PostgreSQL 17.

## Чистая установка

Нужны Node.js 22+ (CI использует 24), npm и PostgreSQL 17. Для стандартной локальной установки подходит Docker Desktop.

1. Скопируйте .env.example в .env и настройте DATABASE_URL.
2. Запустите Docker Desktop, затем `docker compose up -d postgres`.
3. Выполните `npm.cmd ci`, затем `npm.cmd run db:migrate` для пустой базы.
4. При необходимости импортируйте контент через `npm.cmd run import:all` и `npm.cmd run import:charactercontent`.
5. Запустите `npm.cmd run web` и откройте http://localhost:3000/tabletop.

## Обновление существующей базы

Сохраните старые .env и data. Не удаляйте БД/volume и не запускайте повторный импорт ради обновления. Сначала остановите запись, сделайте и проверьте копию; затем зарегистрируйте прежнюю версию через db:adopt и примените только новые миграции. Для уже используемой БД проверенная свежая копия обязательна.

Полные команды: [DATA_SAFETY_RU.md](DATA_SAFETY_RU.md). [Протокол](QA_v0.36_RU.md) · [Принятый roadmap](ROADMAP_RU.md).

Коллекция содержит 1860 уникальных изображений в `data/token-packs/first-dnd`, плюс прежние значки. Автоматический подбор, ручной выбор, цвет рамки и портреты сохраняются. У изображений коллекции остаются исходные цвета; цвет символов меняется отдельно.

## Проверка

```sh
npm test
npm run i18n:audit:ui
npx playwright install chromium
npm run test:tabletop:browser
```

Тесты используют временную БД PGlite, ваша PostgreSQL-база не нужна. В Linux для установки системных библиотек Chromium: `npx playwright install --with-deps chromium`. Ручная проверка: [QA_v0.32.3_RU.md](QA_v0.32.3_RU.md).

## Разработка

[GitHub](https://github.com/Basnik604/dnd-card-table) — источник кода; [Linear](https://linear.app/basnik/project/dnd-card-table-e31cb830fbea) — план и зависимости. Работаем в `feature/*`/`fix/*` и открываем PR с проверками. `main` остаётся стабильной версией. Подробнее: [CONTRIBUTING.md](CONTRIBUTING.md).

Актуальная локализация: [docs/LOCALIZATION_RU.md](docs/LOCALIZATION_RU.md). Файлы `UPDATE_*` описывают исторические версии, а не текущий roadmap.
