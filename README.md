# D&D Card Table v0.32.1

Локальный стол мастера D&D: библиотека контента, создание и развитие персонажей, инвентарь, заклинания, броски и бой; сессии с локациями, картами, сеткой, этажами и токенами. Эта версия начинает Workspace — рабочее пространство вокруг существующей карты.

## Новое в 0.32.1

Локации, инспектор и подсказки можно закрывать и возвращать. «Только карта» освобождает место, «Вернуть панели» восстанавливает прежнюю раскладку. Видимость панелей и вкладка инспектора запоминаются в этом браузере отдельно для каждой сессии. Есть сброс. Черновики карты и токена сохраняются при переключении панелей.

Размеры доков, перенос существующих панелей и вкладки реализованы в 0.32.1. Раскладка v1 автоматически преобразуется в v2. В 0.32.2 добавлены панели выбранного персонажа, библиотека существ и пресеты, см. [roadmap](ROADMAP_RU.md). Подключение игроков планируется в 0.33. Сейчас сервер рассчитан на локальную работу мастера и не имеет полноценной авторизации и прав игрока.

В 0.32.3 карта занимает весь экран, панели свободно двигаются и меняют размер поверх карты. Кнопка «Закрепить панели» возвращает доки.

## Запуск

Нужны Node.js 22+ (CI использует 24), npm и PostgreSQL. Для локальной базы можно использовать Docker Desktop.

1. Откройте терминал в папке проекта. Скопируйте `.env.example` в `.env` и укажите `DATABASE_URL`.
2. Если базы ещё нет: `docker compose up -d`.
3. Установите зависимости: `npm ci`.
4. Для новой базы примените миграции: `npm run db:migrate`.
5. При необходимости наполните библиотеку: `npm run import:all` и `npm run import:charactercontent`. Импорт требует интернета.
6. Запустите `npm run web` и откройте **http://localhost:3000/tabletop**.

Для обновления работающей v0.31.2 используйте прежнюю `.env` и базу данных. В 0.32.2 новых миграций нет: пересоздавать базу, удалять Docker volume или повторно импортировать контент не требуется. Перед сменой версии сохраните обычную резервную копию БД. Карты, токены и персонажи хранятся в ней, личная раскладка — в браузере.

Коллекция содержит 1860 уникальных изображений в `data/token-packs/first-dnd`, плюс прежние значки. Автоматический подбор, ручной выбор, цвет рамки и портреты сохраняются. У изображений коллекции остаются исходные цвета; цвет символов меняется отдельно.

## Проверка

```sh
npm test
npm run i18n:audit:ui
npx playwright install chromium
npm run test:tabletop:browser
```

Тесты используют временную БД PGlite, ваша PostgreSQL-база не нужна. В Linux для установки системных библиотек Chromium: `npx playwright install --with-deps chromium`. Ручная проверка: [QA_v0.32.3_RU.md](QA_v0.32.3_RU.md).
