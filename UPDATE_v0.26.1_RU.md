# D&D Card Table v0.26.1 — hotfix live-roll / Channel Divinity

## Что исправлено

В v0.26.0 интерактивный бросок нового Channel Divinity мог выполнить действие на сервере, но получить обычный HTML-редирект вместо JSON. В окне костей это выглядело как `Unexpected token '<', "<!DOCTYPE ..." is not valid JSON`.

Исправление v0.26.1:

- live-roll теперь явно помечает запрос как JSON через `_response=json`;
- сервер распознаёт этот флаг независимо от заголовка `Accept`;
- клиент проверяет `Content-Type` и больше не пытается разбирать HTML как JSON;
- при неожиданном HTML выводится понятное предупреждение, что действие могло уже потратить ресурс;
- механика Channel Divinity, база данных и правила расхода ресурса не менялись;
- новых зависимостей и SQL-миграций нет.

## Важно после ошибки v0.26.0

Если ошибка уже появилась после нажатия Divine Spark/Turn Undead, сначала обновите страницу. Действие могло успеть выполниться и потратить одно использование, даже если старый счётчик на странице остался прежним. Не нажимайте способность повторно до обновления страницы.

## Установка поверх v0.26.0

1. Остановите сервер (`Ctrl+C`).
2. Распакуйте `dnd-card-table-v0.26.1-live-roll-hotfix-ru.zip`.
3. Скопируйте содержимое поверх рабочей папки с заменой совпадающих файлов.
4. `.env`, PostgreSQL и пользовательские данные не удаляйте.
5. Запустите `npm.cmd run web`.
6. В браузере нажмите `Ctrl+F5`.
7. Внизу страницы должно быть `v0.26.1`.

## Быстрая проверка

1. Откройте жреца 3 уровня с 2/2 Божественного канала.
2. Нажмите «Бросить лечение» у Божественной искры.
3. Окно костей должно показать реальный результат, без JSON/DOCTYPE ошибки.
4. Счётчик ресурса должен сразу смениться на 1/2 без перезагрузки страницы.
5. Нажмите `Ctrl+F5`: значение должно остаться 1/2.
6. Проверьте ещё один live-roll, например Turn Undead или Second Wind, если доступен.
