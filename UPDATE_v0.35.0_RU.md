# v0.35.0 — инициатива и ходы на карте

По выбору пользователя бой реализуется перед Online. Окно «Бой» выбирает участников из токенов текущей сцены, сохраняет ручную инициативу, показывает порядок, текущего участника и раунд. Доступны начало, следующий/предыдущий ход и завершение. Активный токен подсвечен.

Состояние хранится на сервере отдельно для каждой сцены, защищено revision от перезаписи устаревшей вкладкой. Обновление при несохранённой инициативе требует подтверждения. Удалённые/перенесённые токены исключаются при обновлении; отсутствие активного токена останавливает бой. Карта, HP и ресурсы не меняются.

Новая миграция 024_tabletop_combat.sql. Сервер стола применяет её при инициализации; для управляемого обновления можно выполнить npm.cmd run db:migrate. Используйте прежнюю .env и базу.

Это ручной трекер ходов для локального мастера. Равенство инициативы разрешается стабильной сортировкой ID. Автоматические броски, эффекты и многопользовательский режим — отдельные этапы. Протокол QA_v0.35.0_RU.md.
