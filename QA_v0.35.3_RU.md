# Личная проверка v0.35.3 (необязательная)

Автоматические проверки покрывают расчёты, отмену, повторное подтверждение, устаревшие данные и интерфейс. Этот протокол нужен для самостоятельного знакомства с обновлением.

1. Начните бой и снизьте HP персонажа до нуля. В панели «Бой» откройте «Спасброски смерти и восстановление»: состояние — умирающий, на карте появляется бессознательность.
2. В его собственный ход введите физический d20 = 10. Предварительный расчёт не меняет данные; отмена тоже. После подтверждения появляется один успех. Второй бросок в тот же ход отклоняется.
3. Перейдите к следующему собственному ходу: натуральная 1 даёт два провала; натуральная 20 восстанавливает 1 HP и сбрасывает счётчики. Три успеха стабилизируют при 0 HP; три провала означают смерть.
4. При 0 HP обычный урон даёт один провал, критический — два. В предварительном расчёте мастер может уточнить критический урон. Урон по стабильной цели снова запускает умирание. Проверьте поглощение временными HP.
5. Выберите живого помощника и «Стабилизация: Медицина». Учитываются Мудрость и владение/экспертиза; успех при результате 10. Действие списывается только после подтверждения. Мастер может выбрать исключение без стоимости.
6. Стабильной цели выберите восстановление после отдыха. Бросок задаёт 1d4 игровых часа; подтверждайте только после истечения этого времени в истории. Результат — 1 HP.
7. Обычное лечение погибшей цели отклоняется. «Воскрешение мастером» требует явного подтверждения и HP от 1 до максимума; расход компонентов и заклинаний мастер учитывает отдельно.
8. У NPC по умолчанию смерть при 0 HP. Включите «Считать NPC персонажем» и подтвердите: становятся доступны спасброски смерти. Выключение также требует подтверждения.
9. До подтверждения измените HP или ход: старый результат должен отклониться. Перезагрузите страницу и проверьте сохранение HP/счётчиков и согласованность с листом персонажа.

Windows: перезапустите сервер через `npm.cmd run web`, затем Ctrl+F5 в браузере.
