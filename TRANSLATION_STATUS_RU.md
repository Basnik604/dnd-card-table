## Известные ограничения источника

Некоторые английские описания уже содержат склеенные таблицы или перемешанные предложения. Замеченные случаи перечислены в `data/translations/source-quality.json`: Deck of Illusions, Mysterious Deck, Ring of Shooting Stars, Staff of Fire, Wand of Wonder. Список составлен по фактически обнаруженным примерам и не является полным аудитом исходника.

Такие дефекты нельзя достоверно исправить одним переводом. Их числовое содержимое сохранено; восстанавливать английский импорт и затем обновлять перевод следует отдельно. Перед использованием спорного правила нужно сверить исходный текст с соответствующим изданием.

## Установка и продолжение работы

Подробная инструкция для Windows находится в `INSTALL_RU.md`.

1. Остановить сервер и сделать копию существующей рабочей папки. Сохранить `.env` и резервную копию PostgreSQL отдельно: копирование папки не копирует базу.
2. Скопировать содержимое архива в эту рабочую копию, объединяя папки и заменяя совпадающие файлы. Сохранить прежние файлы, которых нет в обновлении. Выполнить `npm.cmd ci`, затем `npm.cmd run web` (на Linux/macOS — `npm`). Внешний переводчик для готового пакета не нужен.
3. Проверить текущую базу командой `npm run i18n:audit`. Если база совпадает со снимком, ожидается ноль непокрытых сегментов.
4. Для дальнейшей работы: исправить повреждения английского импорта, вычитать терминологию и неоднозначные игровые условия, затем помечать действительно проверенные записи как `reviewed`.

Отдельный контрольный архив содержит исходный запрос, ответы переводчика, план разбиения и воспроизводимые скрипты сборки и постредактирования. Архив обновления не требует этих промежуточных данных для использования перевода.
