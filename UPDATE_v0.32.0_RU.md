# v0.32.0 — первый этап Workspace

Карта остаётся центральной; локации слева, инспектор справа, подсказки снизу. Панели можно закрывать и возвращать верхними кнопками. Эти кнопки доступны и во время сохранения данных.

«Только карта» скрывает панели, «Вернуть панели» возвращает прежнюю раскладку. Выбор токена открывает инспектор. Видимость панелей, режим карты и вкладка инспектора запоминаются в этом браузере для каждой сессии и сохраняются при переключении этажей.

«Сбросить раскладку» возвращает исходные панели. Карта, персонажи, токены и черновики форм сохраняются. Повреждённые настройки заменяются стандартными. Если браузер запретил запись, раскладка работает до ухода со страницы и показывает сообщение.

## Установка для проверки

1. В GitHub откройте ветку `feature/v0.32.0-workspace-shell` или PR v0.32.0. Для скачивания выберите Code → Download ZIP.
2. Остановите прежний сервер. В новой папке используйте прежнюю `.env` и ту же базу данных.
3. Выполните `npm ci`, затем `npm run web`.
4. Откройте **http://localhost:3000/tabletop**. Внизу страницы должна быть версия **0.32.0**.

Новых миграций нет. Базу не пересоздавайте. Пакет изображений уже входит в репозиторий.

## Проверка за несколько минут

1. Откройте сессию с картой и токенами. Закройте локации и инспектор крестиком, верните верхними кнопками. Карта занимает освободившееся место.
2. Измените имя токена без сохранения. Скройте/верните инспектор: черновик остаётся. Верните исходное имя, если изменение не нужно.
3. Включите «Только карта», затем «Вернуть панели». Выбор токена в режиме карты открывает его инспектор.
4. Скройте локации, включите подсказки, обновите страницу. Раскладка восстанавливается. На другом этаже этой сессии она та же, у другой сессии — собственная.
5. «Сбросить раскладку» возвращает локации и инспектор и закрывает подсказки. Игровые данные не меняются.
6. Проверьте токен на сохранённой сетке 50, 70 и 150 px: переместите и обновите страницу. Размер и положение соответствуют клеткам.
7. Уменьшите окно или откройте с телефона: блоки располагаются вертикально, кнопки доступны.
