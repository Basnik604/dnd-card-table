# Личная проверка v0.32.3 — свободные окна

Дата: ____ Браузер: ____ Коммит: ____
Заполняйте результат: ПРОШЁЛ / НЕ ПРОШЁЛ / НЕ ПРОВЕРЯЛ.

Запуск на прежней базе: npm.cmd ci, затем npm.cmd run web. Откройте существующую сессию.

| № | Действие | Ожидаемый результат | Результат |
|---|---|---|---|
| 1 | Открыть локацию | Карта занимает всю страницу, локации и инспектор находятся поверх неё | |
| 2 | Взять заголовок окна мышью и двигать вверх/вниз/влево/вправо | Окно свободно перемещается, карта не сдвигается вместе с ним | |
| 3 | Потянуть каждую из четырёх сторон и четырёх углов | Меняются ширина/высота; заголовок остаётся доступным | |
| 4 | Открыть инвентарь, заклинания, способности | Несколько окон видны одновременно; щелчок выводит окно поверх остальных | |
| 5 | Ввести несохранённое поле и двигать/растягивать/закрыть/открыть окно | Значение поля остаётся | |
| 6 | Переключить «Закрепить панели» / «Свободные окна» | Доки и свободные окна переключаются; черновики листа остаются | |
| 7 | Изменить расположение/размер и обновить страницу | Геометрия сохранена для этой сессии; несохранённые формы не гарантируются после перезагрузки | |
| 8 | Включить «Только карта», затем вернуть панели | Окна скрываются и возвращаются на прежние места | |
| 9 | Уменьшить окно браузера до ширины телефона, затем увеличить | Панели остаются доступными; прежняя геометрия большого окна восстанавливается | |
| 10 | Фокусировать заголовок или край через Tab, нажимать стрелки | Перемещение/размер меняется на 10 px; Shift + стрелка на 1 px | |
| 11 | Сменить локацию/этаж, затем вернуться | Раскладка сессии сохраняется, карта и токены прежние | |
| 12 | Нажать «Сбросить раскладку» | Окна возвращаются в исходные позиции; игровые данные прежние | |
| 13 | Передвинуть токен и карту через свободное место между окнами | Обычные действия карты работают | |
| 14 | Открыть другую сессию | Её раскладка независима | |

При ошибке запишите шаг, ожидаемое/фактическое поведение и приложите снимок.
