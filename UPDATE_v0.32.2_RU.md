# v0.32.2 — панели данных персонажа (BAS-8)

Выбранный токен персонажа открывает инвентарь, заклинания, способности и ресурсы из существующего листа. Панели используют прежние серверные действия и записи: отдельной копии персонажа нет. Для монстра или НИП контекст персонажа очищается. Библиотека ищет существ и открывает исходную запись.

Добавлены пресеты «По умолчанию», «Подготовка» и «Игра». Личная раскладка v2 сохраняется с добавлением новых панелей. Черновики остаются при скрытии, переносе, режиме карты и смене пресета; смена персонажа и обновление требуют подтверждения при черновике. Изменение в другой вкладке предлагает обновление. Удаление выбранного токена защищает черновик; исчезновение токена из сцены блокирует старые формы.

Основа — PR #2, ветка feature/v0.32.1-workspace-docks. Новых миграций БД нет. Для обновления используйте прежнюю .env и базу, выполните npm ci и npm run web. Не требуется пересоздание базы или повторный импорт.

Ограничения: локальный мастер, без прав игроков. Для сохранения загруженных iframe при переносе используется DOM moveBefore; браузер без этой функции отказывает в переносе загруженной панели и показывает причину. Автоматический браузерный сценарий использует сокращённый лист с настоящим действием HP; действия полного листа проверяются отдельно пользователем.

Личный протокол: [QA_v0.32.2_RU.md](QA_v0.32.2_RU.md). Результаты заполняет пользователь; автоматические тесты не заменяют проверку на своей базе.
