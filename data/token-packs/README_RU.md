# Пакеты изображений токенов

Для v0.31.2 установите `dnd-token-pack-first-collection-v1.zip` поверх рабочей папки с `package.json`.

Ожидаемый путь: `data/token-packs/first-dnd/manifest.json` и `data/token-packs/first-dnd/images/`.

Коллекция содержит 1860 уникальных PNG из 1924 исходных файлов. Пакет не включён в ZIP обновления кода и устанавливается отдельно один раз. При следующих обновлениях сохраняйте эту папку. После установки или замены пакета перезапустите сервер.

Без пакета доступны прежние типовые значки и собственные портреты. Уже выбранные идентификаторы изображений сохраняются и восстанавливаются после возвращения пакета.

Подробности: `UPDATE_v0.31.2_RU.md` в корне проекта.
