# Коллекция токенов D&D — пакет изображений v1

Для D&D Card Table v0.31.2 и совместимых последующих версий.

Распакуйте архив в прежнюю рабочую папку, где находится `package.json`. Должны появиться `data/token-packs/first-dnd/manifest.json` и `data/token-packs/first-dnd/images/`. Также установите обновление кода v0.31.2. Перезапустите сервер и обновите страницу через Ctrl+F5.

Источник: предоставленный пользователем архив «1st D&D Token Collection».
1924 исходных PNG, 1860 уникальных изображений, 64 точных повтора, 103 раздела с подразделами. Оригинальные PNG 256×256 сохранены без изменений. Имена файлов заменены стабильными идентификаторами; исходные имена и папки перечислены в `manifest.json`.

Это отдельный пакет данных: не удаляйте его при обновлении кода. Выбор конкретной картинки и цвета внешней рамки выполняется в редакторе токена на игровом столе.
