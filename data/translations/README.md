# Пакет русского перевода

`ru.json` содержит 7 276 контекстных записей машинного перевода. Вместе с 849 встроенными терминами он покрывает все 8 125 отображаемых сегментов приложенного снимка каталога: `pending = 0`.

Перевод получен через Google Translate с разрешения пользователя; выполнены автоматические проверки и ограниченная постредактура. Все записи сохраняют статус `machine`. Полная редакторская проверка правил и терминологии не проводилась.

Файл используется сервером без подключения к переводчику. Архив v0.25.0 предназначен для обновления существующего рабочего проекта v0.24.0: в нём также добавлены изучаемые формы Дикого облика и их боевые действия. Скопируйте содержимое архива поверх копии старой рабочей папки, сохранив `.env` и файлы, которых нет в обновлении. Сохраните резервную копию базы отдельно; при обновлении работающей v0.24.0 зависимости можно не переустанавливать. Подробная инструкция — `INSTALL_RU.md` в корне проекта.

Для обновления уже настроенного проекта после переноса исправленного валидатора можно выполнить `npm run i18n:import -- --input /путь/к/ru.json`. Команда сохраняет существующие записи со статусом `reviewed`, если новая запись имеет статус `machine`.

Проверка снимка каталога: `npm run i18n:audit -- --input data/translations/manifest.json`. Проверка текущей базы: `npm run i18n:audit` при настроенном `DATABASE_URL`. Новый импорт или изменение английского текста может добавить новые непереведённые строки.

`coverage.json` — результат проверки каталога; `ui-audit.json` — отдельная проверка 1 327 извлечённых строк интерфейса. `source-quality.json` перечисляет замеченные повреждения английского источника. Сводка работы и ограничения — в `TRANSLATION_STATUS_RU.md` в корне проекта.
