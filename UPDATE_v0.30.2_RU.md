# v0.30.2 — новые значки и цвета токенов

Накопительное обновление для существующей установки v0.28–v0.30.1. Включает предыдущие исправления сетки, сохранения токенов и восстановления справочника. Новых npm-зависимостей нет.

## Что добавлено

**48 значков** с единым каталогом выбора:

| Группа | Значки |
|---|---|
| Существа — 20 | Все значки из присланного набора: нежить, зверь, дракон, конструкт, аберрация, небожитель, элементаль, фея, исчадие, великан, гуманоид, монстр, слизь, растение, демон, дьявол, дух, паразит, рой, босс. |
| Персонажи и роли — 10 | Персонаж, НИП, торговец, стражник, кузнец, целитель, учёный, знать, заказчик, спутник. |
| Классы — 12 | Варвар, воин, паладин, следопыт, плут, монах, бард, друид, жрец, волшебник, чародей, колдун. |
| Объекты карты — 6 | Сокровища, ловушка, дверь, лестница, портал, метка места. |

Исходные значки существ заменяют прежние схематичные символы. Для остальных категорий подготовлены два дополнительных набора в близкой металлической стилистике. Названия из исходной картинки не отображаются внутри жетона: токен использует собственное имя и номер под ним.

**Цвет значка и цвет рамки настраиваются отдельно.** Перекраска сохраняет тени и светлые грани рисунка. Маленький предпросмотр показывает результат до сохранения. Кнопка «Вернуть исходный цвет значка» возвращает цвет текущего типа и не меняет рамку.

При добавлении нового токена персонажа подбирается значок его основного класса, если класс известен приложению. Портрет из листа по-прежнему имеет приоритет в режиме «Портрет из листа / значок». Чтобы видеть выбранный значок, переключите вид на «Только значок». Загруженные портреты не перекрашиваются.

Ранее созданные токены сохраняют тип значка, позицию, размер, имя, номер, портрет и рамку. Их символы используют новую графику с прежним цветом типа. Сохранённый вручную цвет не сбрасывается после перезапуска.

## Как использовать

1. Откройте **Игровой стол → сессию → локацию → Токены**.
2. Добавьте токен или выберите существующий на карте / в списке.
3. Нажмите **«Каталог значков»** и выберите изображение. Обычный список «Значок» также доступен.
4. Настройте **«Цвет значка»**, при необходимости — **«Цвет рамки»**. Цвет можно выбрать в стандартной палитре браузера или задать её числовыми полями.
5. Для замены портрета значком выберите **«Только значок»**.
6. Нажмите **«Сохранить токен»**.

Для торговца, сундука или другого самостоятельного обозначения добавьте обычного НИПа, задайте нужное имя и выберите соответствующий значок. Двери, лестницы, ловушки и порталы в этом выпуске служат обозначениями на карте. Поведение дверей, переходы между этажами и срабатывание ловушек к ним пока не привязаны.

## Установка

1. Остановите сервер через `Ctrl+C`; PostgreSQL оставьте запущенной.
2. Скопируйте содержимое ZIP **в прежнюю рабочую папку**, разрешив объединение папок и замену совпадающих файлов. Сохраните свой `.env` и базовые файлы, которых нет в архиве. Это обновление существующего проекта.
3. В этой папке запустите:

```powershell
npm.cmd run web
```

4. Обновите сайт через **Ctrl+F5**. Внизу страницы должна быть версия **0.30.2**.

Поле цвета создаётся автоматически при первом открытии игрового стола миграцией `021_tabletop_icon_colors.sql`. Ручной запуск миграций и повторный импорт каталога для этого обновления не требуются.

Если ранее возникала ошибка отсутствующей таблицы `character_content`, инструкция и команда восстановления остаются в `UPDATE_v0.30.1_RU.md`.

## Быстрая проверка

1. Создайте НИПа «Торговец», выберите значок торговца, задайте синий цвет значка и золотую рамку. Сохраните и обновите страницу — выбор и оба цвета должны сохраниться.
2. У нежити выберите другой цвет: должен меняться сам череп. Верните исходный цвет кнопкой под палитрами.
3. У персонажа переключите вид между портретом и значком класса. Портрет должен сохранить свои цвета.
4. Поменяйте клетку со 150 на 70 или 50 px и передвиньте токен: исправление из v0.30.1 сохраняется.
