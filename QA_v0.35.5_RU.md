# Личная проверка v0.35.5 (необязательная)

Обновление упрощает интерфейс. Новые боевые правила не добавлены; серверные расчёты и подтверждение мастера сохранены. Автоматические браузерные сценарии проверяет агент.

1. Откройте бой. Во время игры видны текущий ход, следующая очередь, ресурсы участника, действие и цели. Полная очередь и управление боем свёрнуты. Перезапуск, предыдущий ход, завершение и правка инициативы находятся в «Управление боем».
2. Если есть подготовленное доступное действие оружия/заклинания, оно выбирается первым. Действия без ресурсов нельзя выбрать. При отсутствии каталога используйте «Решение мастера» и «Параметры действия».
3. Выберите действие и цели, рассчитайте результат. Основная карточка показывает итог и изменение HP. Кости, защиты, критический урон при 0 HP и числовая поправка доступны в «Броски и поправки мастера».
4. До подтверждения HP и ресурсы не изменяются. При ожидающем результате выбор действия и целей блокируется. Подтвердите после проверки или отмените — черновик снова доступен. Сетевой сбой сохраняет ожидающий результат для повторного подтверждения.
5. Раскройте «Инструменты мастера»: там переключатель HP, журнал, ручная правка параметров юнита, состояния, восстановление, концентрация и длительные эффекты. Сворачивание раздела не сбрасывает черновики.
6. При 0 HP текущего участника появляется заметная кнопка восстановления. Она открывает нужный раздел и выбирает участника автоматически. При ожидающей проверке концентрации появляется отдельная кнопка с именем персонажа и количеством проверок.
7. Перезагрузите страницу: дополнительные разделы снова свёрнуты, важные уведомления остаются. Проверьте узкое окно: элементы не перекрываются, доступен масштаб текста окна.

Приложение пока является локальным столом мастера. Компактный экран — упрощение интерфейса, а не система авторизации игроков. Движение учитывается вручную; особые эффекты разрешает мастер.

Windows: перезапустите сервер через `npm.cmd run web`, затем Ctrl+F5.
