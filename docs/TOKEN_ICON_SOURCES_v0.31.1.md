# Источники и совместимость токенов v0.31.1

Текущая общая база: этажи и групповой перенос из этой ветки v0.31.0 + **48 основных значков из `dnd-card-table-v0.30.2-fixed.zip`**. Скриншот проблемы показывал нежелательный возврат к общим значкам другой ветки.

- `token-icons-creatures-v1.png`, `token-icons-roles-v1.png`, `token-icons-classes-v1.png`: три исходных атласа из fixed, без изменения байтов. Все 48 записей каталога сохранены точно, включая координаты, цвета, категории и сложные области обрезки.
- `src/web/assets/token-icons/*.png`: только 13 дополнительных ролей и рас, которых нет в fixed. Они взяты без изменения байтов из `dnd-card-table-v0.30.3-token-art-fix-ru.zip`; эти PNG также совпадают с соответствующими файлами другой v0.31.0.
- `tabletop-icon-art.mjs`: общий каталог; координаты видимой области дополнительных PNG исключают лишние прозрачные поля при отрисовке. Их стандартный голубой цвет оставляет PNG без фильтра, другой выбранный цвет окрашивает светотень.
- `quest_giver` — видимый вариант в каталоге, `questgiver` — поддерживаемое имя из другой ветки. Сохранённый тип не заменяется при чтении или простом переименовании токена.
- `tests/fixtures/token-icon-compat.json` фиксирует ключи обоих выпущенных каталогов, точные 48 записей из fixed и SHA-256 всех используемых изображений. HTTP-тест проверяет реальные статические маршруты сервера, точное содержимое файлов и приоритет fixed для общих типов.

Следующие накопительные архивы следует собирать из этой объединённой базы. Замена только `tabletop-token-model.mjs` файлом из старой ветки теряет часть типов; возврат прежнего `tabletop-icon-art.mjs` откатывает изображения. Нельзя заменять целиком серверный код старой веткой ради её арта: в текущей версии уже есть групповые переносы, защита от конфликтов и память позиций.
