# Локализация v0.32.0

Обычный запуск использует готовый пакет `data/translations/ru.json`. Модель для показа страницы не запускается и не загружается.

`src/localization/runtime.mjs` выбирает перевод из пакета с учётом контекста, затем из словарей, иначе сохраняет оригинал. `LOCALIZATION_PACK` задаёт другой пакет. EN сохраняет исходный текст; пользовательские имена исключаются из общего перевода. Идентификаторы, значения форм и игровые формулы сохраняются.

Клиент `assets/i18n.js` использует UI-словари и готовый словарь `GET /api/localization/dictionary`. Живого модельного fallback через `/api/i18n/translate` нет. Стол использует общий RU/EN-словарь `assets/tabletop-i18n.mjs`.

## Команды

- `npm run i18n:audit` — покрытие каталога из БД.
- `npm run i18n:audit:ui` — статические строки интерфейса без БД.
- `npm run i18n:export` — выгрузка каталога для перевода.
- `npm run i18n:translate` — отдельная генерация с явно настроенной моделью.
- `npm run i18n:import -- --input ПУТЬ` — импорт подготовленного пакета.

Экспорт/аудит/генерация могут читать сохранённый каталог через `--input`; параметры реализованы в `scripts/localization/cli.mjs`.

Провайдер по умолчанию обращается к локальному Ollama: `http://127.0.0.1:11434/api/chat`. Требуются установленная модель и `LOCALIZATION_MODEL`. Фоновый worker работает только при одновременных `LOCALIZATION_AUTO=1` и `LOCALIZATION_MODEL`. Для готового пакета эти настройки не нужны.

Другой endpoint задаётся через `LOCALIZATION_URL`; внешний адрес дополнительно требует явного `LOCALIZATION_ALLOW_REMOTE=1`. Генерация проходит проверки сегментов и игровых обозначений, пакет записывается атомарно с блокировкой.

## История

`translation-engine.mjs` и `full-sync.mjs` остались от прежней версии и не используются обычным сервером. Инструкции v0.23 про Xenova/Transformers, `i18n:full`, `i18n:sync`, `.localization/ru-cache.json` и `/api/i18n/translate` устарели.

Модельный кэш `.localization/` больше не отслеживается в текущем дереве Git. Историю не переписываем: старые коммиты всё ещё содержат эти данные. Готовые переводы `data/translations/` сохраняются. Исторический отчёт — `TRANSLATION_STATUS_RU.md`.
